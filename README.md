# Automatic Soil Moisture Monitoring Using ESP32 and KiwisIoT

## About the Project

The **Automatic Soil Moisture Monitoring System** is an IoT-based project designed to monitor the moisture level of soil in real time.

Using an ESP32 microcontroller and a soil moisture sensor, the system continuously measures the water content in the soil and sends the readings to the KiwisIoT platform through Wi-Fi. Users can remotely monitor soil moisture levels through the KiwisIoT dashboard and understand when plants need watering.

This project demonstrates how IoT technology can support smarter plant care and efficient water management.
